##  Descripción del Proyecto
Este repositorio contiene la implementación de un **Sistema de Recomendación** desarrollado en Python utilizando el algoritmo **K-Nearest Neighbors (KNN)** con asistencia de **GitHub Copilot**.

## Herramientas Utilizadas
- **Lenguaje:** Python 3.12
- **Librerías:** `pandas`, `numpy`, `scikit-learn`
- **Asistente de IA:** GitHub Copilot
- **Control de Versiones:** Git & GitHub
